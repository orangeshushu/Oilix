# Oilix 2.0.7 (25)

## What's New

- Sign-in fields and buttons stay light and readable even when the iPhone uses Dark Mode. The harbor background is preserved, and other screens follow the system appearance.
- Sampling now includes an ESP32 connection test. Join the device's Wi-Fi in iPhone Settings, then open the Wi-Fi button in Sampling to check whether the device responds.

## Release Scope

The App Store build uses manual Wi-Fi joining in iPhone Settings. The test sends a GET request to the configured device's HTTP root and reports the status. It does not discover devices, capture photos, or import files. The original Oilix Cam workflow remains available. No website or server changes are included.

See [ESP32 Connection Test](../README.md#esp32-connection-test) for the iPhone checklist, expected results, and troubleshooting.

## Verification and Release Status

- November 10, 2026: all 42 unit tests passed, including validation of private device addresses and a simulated HTTP response.
- A development build with the same manual connection workflow was installed and launched on a physical iPhone. The light sign-in layout was checked in a simulator set to Dark Mode. End-to-end communication with the physical ESP32 was not verified.
- The signed App Store build was archived, exported, and uploaded. Apple processed Build 25 and it was attached to version 2.0.7.
- Submitted November 10, 2026 at 6:26 PM EST. App Store Connect confirmed **Waiting for Review** at submission, with automatic release after approval enabled. This is the submission record, not a live availability status.
